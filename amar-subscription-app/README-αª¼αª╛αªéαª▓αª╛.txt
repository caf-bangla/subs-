আমার সাবস্ক্রিপশন — আইফোনে ইনস্টল করার নিয়ম
==================================================

এই ফোল্ডারের ৬টি ফাইল একসাথে রাখতে হবে:
index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png

কেন একবার অনলাইনে রাখতে হবে?
আইফোন শুধু কোনো ওয়েবসাইট (https লিংক) থেকেই অ্যাপ "Add to Home Screen" করতে দেয়।
তাই প্রথমবার ফাইলগুলো একটা ফ্রি হোস্টিংয়ে রাখতে হবে। ইনস্টলের পর অ্যাপ পুরো অফলাইনে চলে,
আর আপনার তথ্য শুধু ফোনেই থাকে — হোস্টিংয়ে কোনো তথ্য যায় না।

পদ্ধতি ১ — GitHub Pages (ফ্রি, স্থায়ী)
1. github.com-এ লগইন করুন → New repository → নাম দিন: subs  → Public → Create
2. "uploading an existing file" চাপুন → ৬টি ফাইল টেনে ছাড়ুন → Commit changes
3. Settings → Pages → Branch: main, ফোল্ডার: / (root) → Save
4. ১-২ মিনিট পর লিংক আসবে: https://আপনার-ইউজারনেম.github.io/subs/

পদ্ধতি ২ — Netlify Drop
1. app.netlify.com/drop খুলুন (ফ্রি অ্যাকাউন্টে লগইন)
2. পুরো ফোল্ডারটা টেনে ছেড়ে দিন → একটা https লিংক পাবেন

আইফোনে ইনস্টল
1. ঐ লিংকটা অবশ্যই Safari-তে খুলুন
2. নিচের শেয়ার বাটন (⬆️) → "Add to Home Screen" → Add
3. হোম স্ক্রিনের আইকন থেকে একবার খুলুন — এরপর ইন্টারনেট ছাড়াই চলবে

জরুরি কথা
- হোম স্ক্রিন থেকে অ্যাপ মুছে দিলে ভেতরের তথ্যও মুছে যাবে। মেনু (⋯) → "ব্যাকআপ নিন" দিয়ে
  মাঝে মাঝে ফাইলটা Files / iCloud Drive-এ রেখে দিন।
- ওয়েব অ্যাপ নিজে থেকে নোটিফিকেশন পাঠাতে পারে না (তার জন্য সার্ভার লাগে)। তাই প্রতিটা
  সাবস্ক্রিপশনে "📅 আইফোন ক্যালেন্ডারে রিমাইন্ডার যোগ করুন" চাপুন — iPhone Calendar
  নির্দিষ্ট দিন আগে সকাল ৯টায় আর ঐ দিন সকাল ৯টায় অ্যালার্ট দেবে, প্রতি মাসে/বছরে নিজে থেকেই।
- পরে অ্যাপ আপডেট করলে sw.js ফাইলে 'amar-subs-v1' কে v2 করে দিন।
